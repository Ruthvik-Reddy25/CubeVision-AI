# 🧩 CubeVision AI

An AI-powered Rubik's Cube solver that uses computer vision to detect cube colors from a mobile camera and computes an optimal solution using the Kociemba algorithm.

---

## ✨ Features

- 📷 Mobile camera integration
- 🎨 OpenCV-based color detection
- 🧠 Kociemba optimal solving algorithm
- ⚛️ React frontend
- ⚡ FastAPI backend
- 🎮 Interactive 3D cube visualization
- 📱 Responsive design

---

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Ruthvik-Reddy25/CubeVision-AI.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate      # Linux/macOS
pip install -r requirements.txt
uvicorn main:app --reload
```

## 📖 Usage

1. Open the application.
2. Read the instructions.
3. Scan all six cube faces.
4. Wait for color detection.
5. View the optimal solution.
